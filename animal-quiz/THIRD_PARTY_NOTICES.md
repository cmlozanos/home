# Créditos

Adaptación del Quiz de Animales de este proyecto familiar a HTML, CSS y JavaScript locales. Conserva sus veinte preguntas, alternativas, puntuación, rachas, trofeos y repaso ponderado. No incluye el servidor, sus credenciales, perfiles personales ni sus partidas.

Ilustraciones SVG e iconos originales para esta versión. El reto educativo es una copia del módulo común del catálogo. No utiliza Three.js, gráficos de terceros, fuentes remotas, anuncios ni seguimiento.
