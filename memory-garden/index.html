¡Todas juntas!

Un jardín para recordar

Toca dos cartas y encuentra los animales iguales. El ojo permite mirar otra vez. Puedes usar Tab y Enter con un teclado.

No hay reloj ni vidas. Los tres botones de puntos eligen 4, 6 u 8 parejas. El sonido empieza apagado.

Instalar y jugar sin conexión

Android: menú de Chrome → Instalar aplicación o Añadir a pantalla de inicio. iPhone / iPad: Compartir → Añadir a pantalla de inicio. Abre una vez con conexión para guardar el juego.
