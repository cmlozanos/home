# Ampliación del universo y juegos infantiles · 19-09-2026

## Alcance solicitado

Revisar las colisiones de Órbita y acercar sus funciones a las documentadas para Stellar Playground, además de investigar juegos web infantiles y publicar nuevas adaptaciones en el repositorio personal. Se conserva el catálogo existente, el juego de coches y los guardados v1 de Órbita. No se cambia la configuración de GitHub Pages ni se añaden servicios, cuentas, anuncios o costes.

Nuevas carpetas autónomas: `memory-garden`, `shape-studio`, `little-atelier`, `maze-meadow`. Sus entradas se añaden al catálogo de `home`. Cada proyecto contiene su Makefile, herramientas, arte original, avisos de licencia y PWA con caché aislada.

## Referencias y decisiones documentadas

- [Auditoría del producto del museo](../orbit-lab/STELLAR_AUDIT.md): fuentes oficiales de Clark Planetarium/Ideum, inventario, estado anterior y diferencias de la implementación.
- [Investigación de juegos infantiles](children-games-research.md): repositorios, commits, licencias y fragmentos examinados. Las estrellas de GitHub son una señal de interés de desarrolladores, no una medición de uso infantil.
- Canvas2D/SVG y JavaScript clásico sin dependencias de producción mantienen el objetivo Chrome 95. Las animaciones no necesitan WebGL.
- La simulación de evolución, habitabilidad y colapso usa reglas lúdicas originales, no parámetros extraídos del software comercial del museo.

## Verificación reproducible

```sh
make check check-games
CHROME95_PATH='/ruta/al/Chromium-95' npm test -- --workers=1
npm run serve
make screenshots
```

Las pruebas numéricas verifican órbitas, contactos rápidos, masa y momento, ramas de evolución y eyección, límites de cuerpos, habitabilidad/vida/colonización y 300 laberintos deterministas completamente conectados. También verifican barajas y bloqueo de parejas, colocación correcta de formas, pincel y guardado, recursos offline y aislamiento entre siete service workers.

La matriz de navegador incluye tablet 1280×800, teléfono 360×740 y 740×360, WebKit y un ejecutable real Chromium 95.0.4630.0 (Mac ARM, snapshot oficial 917397). Cubre gestos con ratón/touch/multicontacto, todos los niveles, fin y siguiente partida, pausa, guardado/recarga, almacenamiento bloqueado, PNG exportado, cancelación de arrastre, cambios de tamaño y offline. Las pruebas offline se ejecutan en Chromium; el arnés de WebKit no admite esa emulación. La ronda completa de 60 segundos se ejecuta una vez por motor Chromium actual/antiguo y no se duplica para cada orientación.

## Límites de la validación

No se ha tenido acceso físico a la Samsung SM-T530NU/Android 5.0.2. Ejecutar Chromium 95 demuestra compatibilidad con ese motor, pero no mide RAM, GPU, calentamiento ni respuesta de su pantalla táctil. No se promete rendimiento idéntico al ordenador dedicado de la exposición, ni paridad visual o científica exacta con el producto comercial.

Una instalación PWA requiere una primera apertura con conexión. Las partidas y dibujos se guardan en el navegador del dispositivo, no se sincronizan entre equipos. Borrar sus datos de navegación borra también esos guardados. Los viajeros fuera del área del universo y los efectos transitorios están acotados para limitar el coste en dispositivos antiguos.
